## 1. 产品目标与范围
为马来西亚股票（Bursa Malaysia）提供**单网页融资历史回测计算器**。核心目标是研究股票股息能否覆盖券商融资成本，并评估股息偿债、再融资买入、风险补仓、卖股还款与净资产的长期变化。币种 MYR。只考虑**券商融资**，不考虑个人贷款、信用卡贷款。

## 2. 已确认业务规则
1. 用户选择马股股票代码、历史回测开始日期；结束日期默认**今天**。以历史真实股价及股息事件逐日回测，不用今天股价反推历史。
2. 用户设定初始自有本金、目标融资比率 LSR（示例 60%）、再融资触发 LSR（示例 55%）、Margin Call LSR（示例 70%）、强制卖出 LSR（Excel 示例 80%）、固定融资年利率。
3. 每日计算融资利息，按月汇总并**计入融资贷款本金**，下一期利息按更新后的余额计算。
4. 收到股息后，先将股息用于偿还融资贷款，贷款余额下降。
5. 当实际 LSR **下降至或低于**可设置的再融资触发值（如 55%）时，模拟增加券商贷款并买入股票，目标是恢复至用户设置的目标 LSR（如 60%）。触发可来自股息还款或股价上涨。
6. 当 LSR 达到 Margin Call 阈值时，整个回测**固定使用一种策略**，不可中途切换：
   - **现金补仓**：仅补足解除追缴所需缺口；模拟现金加入抵押资产，不直接偿还贷款。用户确认 Excel 的 Manual Top-up 是加至抵押价值的处理。
   - **卖股还款**：卖出所需数量的股票并以卖出款偿还融资贷款，仅卖到解除追缴所需程度。
   两种方式都以**略低于追缴阈值**为终点，不自动回到目标 LSR。需采用可解释的最小安全余量，并记录补仓/卖出金额。
7. 用户可在独立的**高级设定**界面设置各项阈值、利率、策略、交易费用。买卖交易的券商费、清算费、印花税属于**可选**成本，默认不计算，以便与 Excel 对照。
8. 历史股价及股息应**自动获取**；支持手动修改，手动数据优先。自动接口不可用时应提示并允许导入/手动输入，不得悄悄补造股息或价格。
9. 每次打开页面恢复默认，不自动持久化用户输入。支持导出/导入**完整 JSON 配置**（主页面参数、高级设置、人工修正数据）；导入校验版本和数值。结束日期未明确固定时以打开当天为默认。
10. 产品呈现以中文“融资”为主要术语；英文名称 Margin Share Calculator。

## 4. 计算定义（待用 Excel 验证）
- `LSR = outstanding margin loan / eligible collateral market value`。若无有效抵押价值，应显示不可计算/风险状态，不能除以零。
- 每日利息基准：`loan balance × fixed annual rate / 365`（参考 Excel）；每月资本化。需明确是否采用日初或日末余额及闰年口径。
- 股息金额：以符合资格的持股数量乘以每股实际现金股息，按实际**入账日**减少贷款；除息日、登记日与付款日必须区分，数据源若缺付款日需明确处理。
- 再融资买入需同时增加贷款与股票市值，因此不能只按“目标 LSR × 当前市值”粗算借款；应联立求解并考虑买入费用、手数及价格。
- 卖股还款也会同时减少贷款与股票市值；应联立求解以避免过度卖出。现金补仓需区分追加抵押现金与新买股票。
- 交易费用、零碎股、每手股数、现金股息税费、停牌及公司行动的处理须可审计。
- Excel Table2 的异常公式（例如初始贷款行引用价格、CEILING 手数及空 AND 参数）须先测试再确定“完全一致”或“修正后符合业务意图”，不能静默照搬。

## 5. 输出指标
至少显示：期末日终股数、期末股票总市值、期末日终贷款余额、净资产、LSR、累计股息、累计融资利息、利息资本化、现金补仓、卖股成交额、再融资买入、交易费用与抵押现金。所有回测结果指标均需 Tooltip，说明定义、公式、数据来源及适用特殊规则。趋势图至少包含每日股票市值、日终贷款余额、净资产（RM）及 LSR（%）。净资产定义为**股票权益净值 = 日终股票市值 − 日终贷款余额**；不自动纳入外部现金、抵押现金、超额股息现金、其他资产负债或未资本化应计利息。区分**已收到股息**和**应计利息**，避免把年度股息误作每月现金流。股息覆盖率在利息为零时显示“不适用”。

## 6. 初步验收标准
- AC-01：开始日可选，结束日默认当天；仅允许合法区间，未来数据不得伪装为历史数据。
- AC-02：以固定年利率按日计息，并在月度节点资本化，能逐行核对。
- AC-03：股息入账优先还款，触发阈值时自动再融资买股到目标 LSR（考虑手数与费用容差）。
- AC-04：风险策略只能在开始回测前选择，回测过程中始终一致。
- AC-05：现金补仓及卖股还款都仅达到略低于 Margin Call 阈值；金额及数量可追溯。
- AC-06：手动数据覆盖自动数据；缺失历史价格/股息必须显式报告。
- AC-07：交易费用默认关闭；开启后进入交易与净资产计算。
- AC-08：刷新页面恢复默认；完整 JSON 可导出、导入并重跑相同配置（动态结束日除外）。
- AC-09：正常输入、边界值、极端股价、缺失行情、停牌、无股息及资金不足情形均不出现 NaN 或静默错误。

## UI v23 — 初始现金自动分配与 Bursa 交易费用（2026-10-24）

回测参数提供可用现金输入。系统按开始日收盘价、目标 LSR、交易手数及初始买入费，计算最大可负担总整手数；融资股数按目标 LSR 向下取整为整手，自有股数为其余整手。初始现金需求为“自有股数 × 开始日收盘价 + 初始订单费用”；实际 LSR 可因整手取整低于目标。若没有可买整手，不允许启动回测。初始融资金额按融资股数乘开始日收盘价，不将费用并入初始贷款。

交易费用分别计算：券商佣金（百分比与最低收费取较高者）、印花税（按每 RM1,000 或不足部分计费并受上限约束）、结算费（百分比与上限）及可选的佣金 SST。默认参数为 Maybank Cash Trade 示例：佣金0.1%、最低RM8；印花税0.1%，每RM1,000或不足部分RM1，单项上限RM1,000；结算费0.03%，上限RM1,000；普通Bursa上市股票佣金SST默认0。费率可调整以匹配具体券商交易单据。该费用表固定用于所选历史时期，不声称恢复各历史日期费率。

费用入账规则：初始建仓成本由用户输入现金支付并列在首日流水；现金补仓买入成本按外部补仓金额支付并反映在现金补仓列，不增加贷款；再融资买入费用计入贷款；卖股还款从卖出所得中扣除费用后偿还贷款。每日CSV与流水均需显示每日交易费用。自有持股与融资持股分别追踪；融资持股卖出用于偿还贷款，自有持股不自动用于该项还款。

### BUG-007 Yahoo 假期回测调查（2026-11-09）

- **复现背景：** Version 7 Production 在用户回测范围包含 Yahoo 未提供单日收盘价时，会由 `expandYahooCalendarRows` 按日期逐日分类；无法确认闭市的工作日继续拒绝补价。
- **Version 6 / Version 7 差异：** 从可访问的 Git 历史比较，V6 与 V7 的 `market-calendar.mjs` 主分类和 `yahoo-calendar.mjs` 行情展开逻辑一致。V7 的日期可信边界变化是 GitHub PR #6：JSON 中声明的 Yahoo 闭市日只有在本次页面会话独立取得的 Yahoo `^KLSE` 日历同样确认时才可信；旧 JSON 或旧行情快照不能自行建立信任。故不能把错误简单归因于 V7 的日期算法回归。V7 开始暴露数据源/历史覆盖证据缺口，是按设计拒绝未经核实的工作日缺价。
- **已确认根因：** 日历不是完整 Bursa 历史日历，内置逐日休市证据只有少数日期；`^KLSE` 在线日历仅覆盖当次 Yahoo 实际返回日期，覆盖边界外没有完整日期证据。另外，连续多日休市时，展开函数会把合成日期作为下一日期的 `carryForwardFrom`；现改为一直引用最近的实际观察收盘日。
- **日期证据：** Bursa 官方历史图表引用 2015-02-02；2015-02-03 的 Bursa Securities 直接历史公告尚未取得；同期《The Star》市场日历将该日标记为 Kuala Lumpur Market and Public Holiday，The Business Times 同期报道亦称马来西亚金融市场当日因公共假期休市。该日期现以可追溯的独立市场来源记录，不以公共假期名称单独推断。Bursa 2025 年官方资料明确表示 2025-02-11 Bursa Malaysia 因 Thaipusam 关闭，操作于 2025-02-12 恢复；可加入有来源的 Bursa 休市证据。
- **修复方案：** 加入 2025-02-11 Bursa 官方来源记录；按 Yahoo `^KLSE` 实际报价日期建立本次运行时闭市日集合；连续休市日 carry-forward 来源指向前一实际观察行情。市场日历仍将 2015–2026 标记 BLOCKED/PARTIAL，未声称完整覆盖。未经独立运行时确认的 JSON Yahoo 闭市声明继续拒绝；未确认工作日缺价继续阻断；不使用未来价格。
