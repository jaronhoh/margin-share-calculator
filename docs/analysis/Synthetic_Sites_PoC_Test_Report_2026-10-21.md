## 引擎与自动化测试
- 逐日计息：贷款余额 × 固定年利率 / 365；日历月末资本化。
- 当日顺序：日初贷款计息 → 月末资本化 → 付款日股息先还贷 → Margin Call → 再融资。
- 再融资按新增贷款与新增股票抵押市值联立求解；追缴现金计入抵押资产，卖股所得偿还贷款。
- Excel 的交易日标记控制风险动作/再融资，利息按每个日历日累计。
- 强平线规则仍未确认；触及后引擎停止并报告，不模拟未批准的动作。
- 自动测试：`node tests/engine.test.mjs`，**16 PASS，0 FAIL**。覆盖种子值、日息、1/2 月末资本化、股息、再融资、两种追缴策略、费用、交易日门控、无负交易和未决强平停止。

## Site v4 界面修正
- 逐日流水价格列改为“开盘价”；合成序列首日现在严格等于输入的开始日开盘价，后续才开始合成价格变动。引擎使用通用 `price` 字段，不再称作 `close`。
- 新增可编辑股息事件表：付款日、每股 MYR 金额，可添加和删除；匹配同日事件会合计，非法日期/金额会被拒绝。
- 新增股票代码输入框（默认 `1155.KL`），用于标记回测情景；不会联网查询行情。
- JSON 配置导入/导出包含股票代码与股息事件。Site 仍只使用合成行情和股息。

结论：**已完成全期缓存值逐行比较，但 Excel 字面业务等价未通过。** 缓存中没有月末资本化且存在负交易数量；引擎依据 PRD 逐月资本化，并只在触发条件成立时生成非负交易。两种追缴分支是对照场景，并非用户确认的唯一策略。完整指标和容差定义见 Site 源仓库中的 `docs/POC_TEST_REPORT.md` 与 `tests/excel-diff.mjs`。

此核对比较的是工作簿保存的公式缓存结果，并未用 Excel 应用重算全部公式。5 项种子值对照通过不代表完整业务模型通过。
