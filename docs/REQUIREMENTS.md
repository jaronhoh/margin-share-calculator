## B. 回测与融资规则
| ID | 需求 | 状态 |
|---|---|---|
| R-010 | 输入股票代码、初始自有资金、开始日期；结束日期默认当天 | 已确认 |
| R-011 | 自动获取历史每日股价和历史股息；支持手动修正，人工值优先 | 已确认 |
| R-012 | 固定融资年利率，每日计息、每月资本化并加入贷款余额 | 已确认 |
| R-013 | 股息到账后自动用于偿还融资贷款 | 已确认 |
| R-014 | 可设目标 LSR 与较低的再融资触发 LSR；达到触发值时融资买股回到目标 | 已确认 |
| R-015 | 可设 Margin Call 与强制卖出阈值 | 已确认（强平执行规则待定） |
| R-016 | 回测前固定选择现金补仓或卖股还款策略，回测期间不可切换 | 已确认 |
| R-017 | Margin Call 只处理到略低于追缴阈值，不强制恢复目标 LSR | 已确认 |
| R-018 | 现金补仓自动计算最低所需金额；作为新增抵押资产而非直接还贷 | 已确认 |
| R-019 | 卖股还款仅卖出足以解除追缴的数量，卖出所得偿还融资贷款 | 已确认 |

## Excel 输入口径（用户确认）
- R-025：Table2 `H3=11400` 是自有部分股数，`I3=17100` 是融资部分股数，均不是金额。
- `K4=28500` 股；`I4=I3*F4=RM156807` 是股数乘股价换算融资金额。用户已确认 RM9.17 是当日 MAYBANK 股价；行情来源和日期匹配仍待独立验证。

## D. 仍待确认 / 技术验证
- O-001：马股历史价格与现金股息数据提供者及真实可用性，特别是**付款日**。

- O-005：Excel 样本中疑似异常公式的处理：忠实复制还是修正业务逻辑。
- O-006：补仓现金、净资产、收益率与资金投入的会计口径。
